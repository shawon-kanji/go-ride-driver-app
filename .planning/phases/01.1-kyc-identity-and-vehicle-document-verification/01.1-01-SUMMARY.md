## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Added `types: ["jest", "node"]` to tsconfig.json**
- **Found during:** Task 3 (creating the six stub test files)
- **Issue:** With no explicit `types` compilerOption, `@types/jest`'s ambient `describe`/`it`/`expect`
  globals were not being auto-discovered under `moduleResolution: "bundler"`, so `npx tsc --noEmit`
  failed with `Cannot find name 'describe'` etc. on every new test file — blocking Task 3's acceptance
  criteria.
- **Fix:** Added `"types": ["jest", "node"]` to `tsconfig.json` `compilerOptions`. `node` is included
  because `src/api/http-client.ts` already relies on the ambient `process.env` global, which came from
  automatic `@types/node` inclusion before this change; without it, restricting to `["jest"]` alone
  would have broken that file.
- **Files modified:** tsconfig.json
- **Verification:** `npx tsc --noEmit` exits 0 across the whole repo (including pre-existing files)
- **Committed in:** `baca563` (Task 3 commit)

**2. [Rule 3 - Blocking] Installed `@react-native/jest-preset@0.86.2`**
- **Found during:** Task 3 (first `npx jest --watchAll=false` run)
- **Issue:** `jest-expo@57.0.3`'s `jest-expo/android` preset threw `Validation Error: ... jest-expo
  relies on has moved to a separate package. To migrate, please install "@react-native/jest-preset"`
  at test-run time — this repo's `react-native@0.86.2` peer dependency was not auto-installed by
  `npx expo install jest-expo jest`. Matches 01.1-RESEARCH.md's documented Pitfall 3.
- **Fix:** Ran `npm install -D "@react-native/jest-preset@^0.86.2"`.
- **Files modified:** package.json, package-lock.json
- **Verification:** `npx jest --watchAll=false` now passes: 6 suites, 24 todo, 0 failures
- **Committed in:** `baca563` (Task 3 commit)
