radii scale and Plus Jakarta Sans weights 400-800, wired so every existing and future screen
picks them up through the nine shared components in `src/components/`.

Purpose: RESEARCH.md Pitfall 1 is a confirmed, non-hypothetical fact about this repo —
`src/theme/radii.ts` is dead code that `tailwind.config.js` never imports, so all 11
`rounded-*` classes currently resolve against Tailwind's stock defaults. Editing the token file
alone changes nothing visually. Likewise, RN Android will not synthesise Plus Jakarta Sans's
five separate TTF families from a `font-weight` utility — each weight is its own registered
family name, so the weight utilities in use today (`font-medium`/`font-semibold`/`font-bold`)
must be replaced by explicit family classes. This plan does both properly, once, at the
shared-component level, so plans 02-06 through 02-10 inherit them for free.
Output: A wired Tailwind theme, a font-gated splash screen, and nine retokenised components
including a `Button` that supports both shapes the design deliberately uses.
